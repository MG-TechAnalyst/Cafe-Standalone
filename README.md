# Café — Coffee, Food & Good Company

A responsive, single-page café website concept built with plain HTML, CSS and JavaScript. It is a fictional portfolio project, designed to demonstrate front-end layout, responsive styling and small interactive details.

## Features

- Responsive desktop, tablet and mobile layouts (including small screens)
- Mobile navigation with keyboard support
- Menu filters for Coffee, Breakfast, Lunch and Treats
- Interactive sample basket with quantities and a calculated total
- Photo gallery lightbox with keyboard left/right navigation
- Local image assets; no external image URLs or front-end libraries required
- Accessible labels, visible focus styles, reduced-motion support, and a skip link

## Run locally

1. Download or clone this repository.
2. Keep `index.html` and the `assets` folder in the same project directory.
3. Open `index.html` in a browser, or use a local preview extension in your editor.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md` and the entire `assets/` folder to the root of a GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
3. Wait for GitHub Pages to publish the site and use the URL displayed in the Pages settings.

## Important project notes

- This is a fictional café concept, not a commissioned or official website for a real café.
- Images are illustrative and sample menu names and prices are placeholders. Replace them with approved assets and confirmed business information before real use.
- The basket is front-end demonstration only: it does not send an order, process a payment, store data, or connect to a point-of-sale system.
- The location section is a placeholder and must be updated before launch.

## Stack

Semantic HTML5 · CSS custom properties and media queries · Vanilla JavaScript · Local JPEG assets
